# rally_brain — 에이전트 추가 규칙 (루트 CLAUDE.md에 더해)

- 판단 순서는 항상 **규칙 레이어 → LLM**. 규칙으로 결정되는 상황을 LLM에 보내지 않는다.
- **규칙 우선·LLM 격리 (#78)**: 제어값은 레시피·규칙으로 계산하며 기존 범위 제한을 유지한다. LLM은 애매한 상황의 행동 선택·설명·리포트에 사용한다. 상황 판단은 비동기 호출·3 s 타임아웃·pydantic 스키마·행동 허용 목록·현재 안전 상태 검증 후 BT가 적용하고 실패하면 규칙으로 폴백한다. STOP을 해제하거나 로봇에 직접 명령하지 않는다. 기존 `SuggestParams`·`llm_tunable`은 대체 구현 전까지 검증·클램핑·폴백을 유지하며 새 숫자 조절 경로를 연결하지 않는다.
- LLM에 보내는 필드는 `llm.yaml`의 화이트리스트만. 환자 식별 정보·영상·원시 좌표열 금지.
- 행동 트리(`trees/`)의 리프는 `skills.yaml`에 등록된 스킬/행동 이름만 호출. 새 행동은 yaml에 먼저 등록.
- 모든 시도는 `TrialResult`로 발행해야 DB·학습 루프가 돈다. 발행 없는 시도 경로를 만들지 않는다.
- 프롬프트는 `prompts/*.md`에 두고 코드에 문자열로 넣지 않는다.
